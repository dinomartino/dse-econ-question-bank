# DSE Economics question bank

Past paper multiple-choice questions for Hong Kong DSE Economics, as data files: 1,759
questions in 72 topics, from HKCEE, HKALE and HKDSE papers, each in English and Chinese with
its official answer.

## Files

- `manifest.json`: the list of topics (title, number of questions, file, size, checksum) and a
  search index with the plain words of every question.
- `topics/<topic>.json`: the questions of one topic, oldest paper first. A passage shared by
  several questions stands above them. Diagrams are inside the file.

The files are read by a worksheet editor for teachers, which shows them as a read-only bank
to pick questions from. Base address for reading them:

    https://raw.githubusercontent.com/dinomartino/dse-econ-question-bank/main/

## What is not here

No explanations, no marking notes, no student data. Questions whose English and Chinese
versions are not yet matched are left out until they are.
